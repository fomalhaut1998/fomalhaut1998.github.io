小站建设进程

2026-10-04

  1. 关于页推倒重做：顶部 Hero（一份源码 · 六线并行）+ 六条线路各一张卡，每条标出节点位置、实测的 Ping 延迟 / HTTPS 握手 / 首字节 TTFB 与一条比例尺；卡片右下角挂「实时延迟」徽标，可以单条重测，也可以一键重测全部
  2. 关于页第二次打磨：整页浅底改成「主题色 + 不透明度」的一组变量，换主题色整页跟着走（用 @supports 包住 color-mix，不支持时退回绿色兜底值，避免整块背景失效）；技术栈与鸣谢里补上 DeepSeek Harness
  3. 部署链路新增一键脚本 npm run deploy:vercel：自己从 .ai-chat-key 读出 Key 塞进构建环境，再依次 clean / generate / deploy；脚本放 tools/ 不放 scripts/，因为 hexo 会把 scripts/ 下的顶层代码当插件执行，顶层 exit 会让 CI 直接退出
  4. 给 Cloudflare Pages 补了一份同源代理：Vercel 认仓库根的 api/、Pages 认 functions/，两份等价的实现走同一个路由；构建完成后由 after_generate 过滤器自动拷进产物仓库
  5. AI 助手的前端脚本带上「内容版本号」，改完脚本访客不会再拿到旧缓存
  6. 手机端抽屉重做（新增独立样式表，13 个小节）：面板、顶部字标、底部签名、头像、统计胶囊、雪花分隔线、菜单与二级菜单、遮罩、入场动效、深色与无障碍；入场动效从主题的横向错位滑入换成了上浮淡入
  7. 顺手查出抽屉头像从主题原版起就没有呼吸灯：主题那条 #sidebar-menus.open > :nth-child(1) 的权重压过了头像自己的呼吸灯动画；改成两条并行动画（一条管位移、一条管阴影）就都保住了
  8. 头像呼吸灯的两种颜色不再写死：新增一个样式表重新声明同名 @keyframes，颜色从主题色派生（浅色往白里调、深色直接用原色），换主题色不再对不上
  9. 星空特效关掉之后仍在每帧重绘整页画布：加可见性判断（用计算样式而不是 offsetParent，因为那个容器是 fixed 定位），并在主题切换 / 窗口缩放 / pjax 换页时失效重算，每 45 帧再兜底复核一次
  10. 侧栏个人卡的磨砂玻璃只在 1200px 以上启用，窄屏与平板降级成实底面板，滚动时不再逐帧重算背景
  11. 美化面板在手机上重新排过：每段「文字 + 开关」包了一层，窄屏换行时开关不会跟文字分家；背景滤镜三个数字框不再被拆行；主题色那一行改成等宽网格；顺手删掉一个和「恢复默认设置」重复的「恢复默认背景」按钮
  12. 搜索框的 Algolia 三连不再每页阻塞加载（合计 296 KB、压缩后约 88 KB，其实只有点开搜索才用）：改成页面空闲时预取、点开才执行；踩的坑是主题那段代码整包在 window load 里，页面已经 load 过就不会再触发，于是执行期间临时接管 addEventListener 把回调当场跑掉
  13. 首页副标题打字机「丝滑版」：在 head 里用同签名覆盖主题的 Typed.js，逐字淡入（相邻字符的动画重叠成一条流）+ 随机节奏 + 呼吸光标，也不再从 CDN 拉 typed.min.js
  14. 鼠标划过文字时偶尔闪出的 I 形光标修掉了：根因是刷新光标样式时「先删后建」，几十毫秒的空窗里浏览器退回了系统光标；改成样式节点只建一次、刷新只改内容
  15. 旧时光这页自己也改了一遍：加年份分隔器（大号年份 + 「N 条记录」）、日期拆成年份与月日、每条挂上 tl-YYYY-MM-DD 锚点，最早那条不规整的日期单独排；只在浏览器里改 DOM，正文一个字没动
  16. 公告栏每条线路后面多了一串「xx ms」：浏览器发不出 ICMP，就用带随机串的请求量「首字节时间」；全部等页面加载完、错开 180ms 才开跑，超时 8 秒、失败重试一次；徽标锁死最小宽度，从「—」到 82ms 都不会让排版跳动
  17. 留言板 / 信封页改版：只新增一个样式块，作用域锁在这一页（信封与评论区的圆角内边距、窄屏隐藏封底、居中的渐变分隔线）
  18. 侧栏宽度又调了两轮：为了避开右侧悬浮工具条，改成不压缩布局宽度、只加大右侧内边距；最后按「再窄一点点」把侧栏从 360 放到 340px
  19. 修一个只在线上才会出现的 bug：朋友圈页的内联注释里出现了带尖括号的 style / script 标签名，gulp 的 htmlclean 把注释里的标签当成真的开始标签，整页正文被丢弃 —— 线上只剩空白卡片，本地不跑 gulp 完全看不出来
  20. 友人帐与八宝箱的分类标题图标在手机上被裁：风车图标的负外边距约 21.6px，而窄屏卡片左内边距只有 14px，补回 1.6rem 后图标稳定落在标题盒里
  21. 社交二维码点一下不再变成下载：图床域名返回的响应头带 attachment，浏览器直接打开会被下载；改成同页灯箱展示，作者卡被 pjax 重建之后依然生效
  22. 又做了一轮「让页面真正空闲」的性能优化：滚动回调合流成一帧一次、鼠标停住就停掉动画循环、帧率计数器只留一条、主题色没换就不重扫全站元素
  23. 停掉两处看不见的动画：首页卡片小箭头与置顶角标的流光从 top/left 改走 transform，加载遮罩隐藏后不再跑内部动画
  24. 桌面端作者卡干脆去掉实时背景模糊（卡片在滚、背景不动，每帧都要重算高斯模糊）；头像呼吸灯从 box-shadow 搬到合成层（两层静态光晕交叉淡入淡出），手机抽屉那颗只在拉出抽屉时才呼吸
  25. 暗色星空的整页重绘从跟着刷新率限到 30fps
  26. 查出一个只在线上出现的 gulp 问题：压缩 CSS 用的 clean-css 0.x 不认识 @container，会把容器查询整块剥掉、连带吞掉紧随其后的规则，公告栏因此少了一条间距；改成这两个文件不参与 CSS 压缩
  27. 小站资讯卡的时间条多了一格「更新」= 最近一次部署时间：部署工作流在构建后写一个 deploy.json，页面同源读取换算成「N 分钟前」，读不到就用构建时刻兜底，结果缓存十分钟
  28. 把源码仓库也推上了 GitHub（当天六次提交）：旧的 SSH 地址推不动，换成 HTTPS 并清掉旧代理配置才成功
