一份源码 · 六线并行

Hexo 静态站点，同一份构建产物同时分发给 6 条线路（2 条主线路 + 4 条备用线路），全站 HTTPS、实测全部协商到 TLS 1.3 + HTTP/2。下面把每条线路的节点位置、Ping 延迟、HTTPS 握手耗时与首字节响应都摊开写清楚。

  • 6在线线路
  • 2主线路
  • TLS 1.3全站 HTTPS
  • h2HTTP/2 全支持

1.线路信息🚁

本站是纯静态站点，一份构建产物同时推给 6 个托管商：2 条主线路负责日常访问，4 条备用线路负责兜底与分流。六条线路全部支持 HTTPS，浏览器与服务器都能协商到 TLS 1.3 + HTTP/2。下面先逐条说明「它在哪、有什么特点」，再给一张本机实测参数对照表。

数据口径：上表三列全部是 2026-10-04 在站长本机（中国大陆家庭宽带）上用原始套接字分阶段计时得到的 —— DNS 解析 → TCP 三次握手 → TLS 握手 → 发出 GET / 直到收到第一个字节，每条线路采样 4 次后取区间。单位毫秒，是参考值不是承诺值：不同运营商、不同省份、不同时段的差异可以很大，跨国线路尤其明显（相邻两次采样差出一秒很常见，所以只写区间）。
线路卡右下角的「实时延迟」徽标才是属于你自己的数字 —— 它是浏览器用 fetch(mode:"no-cors") 打一次带随机参数的请求量出来的往返耗时，点一下即可单独重测，页面静置五分钟也会自动静默复测一轮。
另外：主域 www.fomal.cc 还通过 Service Worker 把主域链接劫持到缤纷云对象存储，国内访问时会进一步走更快的国内线路。

2.技术栈&框架🧪

按「请求从哪进来 → 页面怎么生成 → 浏览器里跑什么 → 产物怎么构建发布 → 数据存在哪 → 授权怎么给」拆成六层。版本号均为当前实际安装版本，不是官网最新版。

L1接入与边缘Ingress / Edge
  • 边缘网络Vercel · Cloudflare · 腾讯云 EdgeOne · Netlify · GitHub Pages(Fastly) · Render
  • 传输层全站强制 HTTPS：实测六条线路均协商到 TLS 1.3、ALPN 为 h2（HTTP/2）；Cloudflare 侧额外开放 HTTP/3（alt-svc: h3=":443"）。Vercel / Netlify / EdgeOne 均下发 HSTS 响应头
  • 线路分流6 个域名 CNAME 到不同托管商并行分发；再用 Service Worker 劫持主域链接到缤纷云 Bucket，把主站请求分流到国内线路
  • 对象存储缤纷云 S3 兼容 Bucket（静态资源） + 图床：缤纷云 Bucket / SKY CHART BED
  • CDN 源npmmirror · elemecdn · 360 baomitu · jsdmirror · 阿里矢量图标库

为什么要起这个名字
  1. 北落师门距离地球约 25 光年。假设某个人出生的那一刻，有一束光同时从它那里出发，那么等这束光抵达地球时，那个人正好 25 岁——一生中最有希望、最有活力的年纪（所以它很适合当一颗年轻人的「生日星」）。
  2. 在中国南方的秋夜里，它是你能看到的最靠南的亮星之一。南边天空的星星本就比北边稀疏得多，它却偏偏挑了这一片空旷站着（暗示孤独与自立，本来就是人生的主旋律）。
  3. 它周围没有一颗比它更亮的星，独自在秋夜南天发着光，却同时是南鱼座的主星；西方人甚至直接叫它 the Loneliest Star（最孤独的星）。即使身处暗淡、无人同行，也可以自己成为主角，独自灿烂。
  4. 在中国古代星官里，它是「天之军门」：「北落」指北方军垒的藩落，「师门」即军门，《晋书·天文志》写「北落师门，天之军门也」——它是羽林军的北门，古人靠它占候国运与兵事（一颗被托付「守夜」的星：替人间守着北门，也替晚归的人留一盏灯）。
  5. 它的西名 Fomalhaut 出自阿拉伯语 Fum al-Ḥūt，意思是「鱼之口」——正是南鱼座张开的那张嘴。于是同一个名字，东方是「军营的北门」，西方是「游鱼的嘴」：一边是戍守的坚硬，一边是游向深海的自由，一个名字装下了两种性格。
  6. 自 1943 年起，它的光谱就与少数几颗恒星一起成为 MK 分类系统的基准点之一；它也是第一颗在可见光波段拍到系外行星候选者（Fomalhaut b，后来被怀疑只是一团尘埃云）的中心恒星——那次成像本身开创了先例（出名，但不到人人皆知的程度，刚好适合拿来当昵称）。
  7. 2008 年哈勃首次在可见光下拍清它周围的尘埃盘，2023 年韦布望远镜又在那层盘里分辨出三重环带：像一枚套在恒星外的戒指，也像一圈圈年轮——在那层尘埃里，新的行星正在慢慢成形（一个人也可以是一颗安静地造着自己世界的星）。
所以它成了我的签名：光从它那里出发要走 25 年，抵达时我正好又长了一岁；它独自亮在南天，替人间守着一扇北门；就连它身边的尘埃，也还在慢慢孕育新的世界。取名字这件事，说到底就是给自己找一个坐标——愿我也能像它一样，安静、明亮、独自灿烂。

想法
为什么当初会阴差阳错地选择了Hexo这样的静态博客作为自己的网站框架呢？(这直接导致了后面在美化博客的道路上渐行渐远...)。其实最初是看见三叶姐弄了个Hexo博客，觉得好厉害，是二次元风格的(觉得用来装逼十分合适)，于是在她的安利之下自己也萌生了想弄一个博客的想法🌈。后面逐渐了解到，Hexo这种静态博客相比于WordPress这些动态博客，可以不用购买服务器，网站的运营费用主要是域名费用(白嫖)。而采用动态博客就必须自己租云服务器，虽然WordPress部署起来更加简单，不用折腾那么多(但是我是一个比较喜欢折腾的人🤣)。还有一个就是Hexo这个框架非常轻量化，启动速度很快，且可拓展性十分强大，可以自己定义任何东西，非常考验自己的前端基础(虽然很多是cv的)。平时在电脑上装好对应的NodeJs环境，写一写Markdown文件然后直接推送到github仓库就会全自动部署，网站就可以将笔记渲染成十分好看的网页和布局，这种自动化部署和精美的页面是一种能让人十分愉快的体验(当然前期得折腾很多东西啦)。比如我2022年8-12月这段时间花了大量时间来倒腾博客和学习一些前端的知识，逛别人博客时看到好看的就想搬到自己的网站上😂，最后基本上就弄成现在这个样子。同时在B站做的视频也越来越多人看，截止目前为止网站的总访问量已经突破 100w，B 站的粉丝也涨到了 2300 多个，这也算是一点小小的成就和一笔小财富吧！在魔改博客的过程中也认识了非常多志同道合的小伙伴，也少不了各路前端大佬的帮助和指导，在此表示非常感激！群里新加入的小伙伴也越来越多，目前已经有 1000 多位了。在这几个月以来，自己对于Butterfly主题的了解也在逐渐加深，认识到主题作者这种大神的前端功底是如此之深！我自己也从一只不敢动源码的小菜鸡到现在会自己改一些简单源码，在原来主题的基础上进行二次开发。这种能力的提升要全身心去投入才会感受到，这也意味着博客的样式可以根据自己的想法去实现，打造一个完全属于自己的网站。看到很多小伙伴看了自己的视频之后，以自己的教程作为蓝图，参考着搭建起网站就感到非常自豪。目前博客已开源，站长的初衷是让更多小白可以快速搭建起好看好用的个人网站，最后也感谢各位小伙伴的支持！！！

2023 到 2024 年这段时间，我把大部分精力都放在了读研和找工作上，博客就这么被自己搁置了下来📚。2024 年毕业参加工作之后，日子被工作填得满满当当，下班后只想瘫着，更没什么心思打理它😮‍💨。可偶尔打开后台，看到还有人留言、还有人照着我写的教程把自己的站搭起来，心里总会咯噔一下——这明明是自己真正热爱的东西啊。于是趁着今年国庆的假期，把这份热爱重新捡了起来：翻新了关于页，把技术栈、线路信息和这些年欠下的更新都补了一轮，也重新找回了当年折腾博客时那种纯粹的快乐✨。往后尽量保持更新，不再让它一睡就是一两年啦。
